About

Most of my career has been spent inside the plumbing of U.S. health insurance: enrollment files, claims, remittances, eligibility checks, and the systems that move them between providers and payers. I know what a broken 837 looks like and what it costs when one slips through.

Over the last two years I've moved from testing those systems to building tools that test them. That started with an internal automation app now in production, and has grown into AI agents that read mapping documents, derive validation rules for a person to approve, and check data at scale.

I care about AI that people can trust in regulated work: outputs you can trace, decisions a human signs off on, and tools usable by teammates who don't write code.

Built solo

Generic AI validation agent

An agent that reads mapping documents in whatever layout a team uses, proposes how to interpret them, asks clarifying questions, and turns the answers into validation rules a tester approves. It then compares X12 files against Snowflake and produces traceable field-level pass/fail results. First use case: dental claims (837D). It runs as a VS Code extension so teammates with no AI or scripting background can use it in plain language.

  • Python
  • LLM agents
